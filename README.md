# Домашние задания по курсу «Основы Django» профессии «Python-разработчик с нуля»

В этом репозитории расположены решения домашних заданий по курсу "Основы Django":

2.1. Работа с ORM. Задание "Автосалон" (реализация небольшого сайта автосалона, состоящего из 3-х страниц);

3.1. Знакомство с API на примере Django REST framework. Задание "Реализация API отзывов к товару" (реализация небольшой части API магазина, а именно товары и отзывы на них);

3.2. CRUD в DRF. Задание "Реализация API онлайн-библиотеки" (реализация небольшой онлайн-библиотеки, состоящей из 2 сущностей: книги и заказы).
